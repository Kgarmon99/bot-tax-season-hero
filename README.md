# Tax Season Hero

A MoneyBot educational game that teaches high school students how to file taxes through fun, interactive gameplay.

## Play Now

Open `index.html` in any modern browser. No server required.

## How to Play

1. **Choose a Level** — Start with Level 1 and unlock progressively harder challenges
2. **Review Client Documents** — Select the correct tax forms (W-2, 1099, etc.)
3. **Claim Deductions** — Choose legitimate write-offs, avoid audit triggers
4. **Beat the Clock** — File before the deadline for time bonuses
5. **Maximize Refunds** — Help your clients get the best return possible

## Levels

### Level 1: Summer Job Hero
- Simple W-2 scenario
- First-time filer basics
- Learn what a W-2 means

### Level 2: Side Hustle Solver
- W-2 + 1099 income
- Business deductions introduced
- Learn what's deductible

### Level 3: Gig Economy Chaos
- Multiple income streams
- Crypto losses
- Home office deductions
- Audit risk management

## What You'll Learn

- How to read tax documents (W-2, 1099 series)
- Legitimate deductions vs red flags
- Self-employment tax basics
- Filing deadlines and penalties
- Audit triggers to avoid

## MoneyBot Integration

MoneyBot appears throughout the game with helpful tax tips and encouragement. Look for the mascot in the corner for wisdom!
